# Redistributable synthetic fixtures

This publication contains only fixtures required by automated tests, not the original
hardware evidence archive. PNGs under offline-cli-dataset are generated synthetic
stereo images. Their calibration explicitly declares SyntheticFixture. The
recorded-stereo-dataset GREY recordings derive from those PNGs; the reproducible
writer is crates/scancraft-workflow/examples/recorded_stereo_fixture.rs.
The project-origin-gui-render/result bundle is regenerated by scancraft-cli
reconstruct-recordings using those recordings and relative source paths.
The offline-cli-verified project and mesh input JSON are synthetic geometry.

Factory Brown/pose comparison JSON and crates/scancraft-calibration/tests/fixtures
contain synthetic numerical inputs/observations, not genuine calibration values,
proprietary code or captured assets. Their private reference inputs are not bundled;
method/reference hashes identify observations, not a redistributable upstream SDK.
Only the independently written harness source and synthetic numeric results are
included. They do not establish physical scanner calibration or a legal clean-room
certification. Historical documents may cite nonpublished evidence paths; those
measurements remain historical and are not publication verification results.

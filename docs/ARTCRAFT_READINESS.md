# ArtCraft Ecosystem Candidate

ScanCraft is independently maintained and independently buildable. It is not
officially affiliated with, endorsed by, accepted by, or adopted by ArtCraft.
The subtitle expresses an aspiration for future evaluation only.

Evaluation entry points are README.md, ARCHITECTURE.md, Cargo.toml, docs/BUILD.md,
PROJECT_STATUS.md, ACCEPTANCE_RESULTS.md and the license/provenance inventory under
docs/publication. Rust crates separate device acquisition, recordings, calibration,
image preparation, depth, geometry, workflow orchestration, GUI and CLI. No ArtCraft
runtime dependency or API compatibility is claimed. A future integration should
first establish the actual integration contract with maintainers, retain standalone
operation, and qualify calibrated reconstruction and transport reliability.

No ArtCraft pull request, endorsement request or adoption claim is part of this release.
